## 已实际操作验证

- 资料审核 → 生成任务 → 候选结构检查/人工审核/采用 → 题目审核 → 发布课程 → 创建作业草稿 → 单独发布作业 → 学生提交答案与解释 → 申请教师复核 → 教师保存结论/依据/反馈。刷新后记录恢复。
- 学生学习记录能显示教师反馈，保留原始示例反馈；课程问答能追加本地示例回复。
- 策略结构检查、空审核依据拦截、人工审核、发布、填写依据回退到基础策略。
- 生成任务取消后显示已取消，手动继续后重新排队；正常任务完成并生成候选。
- 学生模拟生成示例、教师填写审阅依据，刷新后演练历史可见。
- 作业延期填写新截止时间与原因，学生列表显示更新的截止时间。
- 批量预检空标题逐行报错，错误行阻止创建；修正后可创建全部课程草稿。
- 已发布课程创建修订 v1.0.1 后，资料与题目均回到待审核；题目编辑生成历史记录，恢复历史后仍待审核。已有作业保留其独立快照。
- 教师搜索打开作业详情；学生搜索打开同一份已在进行的作业时，关闭搜索并进入作业页，保留已有答案。
- 管理员页可访问演示账号、额度与备份；额度保存；数据保留预览显示 0 份过期记录，不执行清理。
- 390 × 844 下检查学习记录、学习工作台、教学概况和高级工具。文档宽度 375，小于视口 390，无页面横向溢出；工具页标签允许局部横向滚动。已恢复默认视口。
- `node --check` 检查 app.js / features.js / serve.mjs；浏览器验收结束时无控制台 error。
