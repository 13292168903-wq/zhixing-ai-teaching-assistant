# 知行工作空间 · 纯前端体验版

在项目根目录运行 `node platform/prototype/serve.mjs`，访问 http://127.0.0.1:4180/ 。无构建或安装步骤。请使用本地服务器体验完整的浏览器存储与导出行为。

界面固定为布局 A。采用暖白、墨色与钴蓝，使用本机中文字体；正文 16 px，桌面搜索入口 360 × 46 px。旧链接中的 `?variant=` 不再改变布局。

## 体验入口

左上角的工作空间按钮可切换教师、学生和管理员。切换是本地演示，不代表真实身份认证。

- 教师：新建课程、资料本地预览及审核、知识点与正文编辑、题目/答案/解析/量规编辑、修订历史、课程审核发布、版本修订。
- 任务中心：配置题型/难度/数量/要求、排队与处理、取消/中断/继续、候选检查/审核/修订/采用/导出。
- 作业与班级：班级和邀请管理、加入教学班、作业快照草稿与独立发布、截止时间延期、进度、作答复核和反馈。
- 学生：课程资料、练习和作业、答案与解释、提示、学习记录、复核申请、课程示例问答、复查任务与数据导出。
- 高级工具：课程模板、CSV/JSON 批量预检、课包导入导出、教学能力绑定、学生模拟演练与审阅历史、策略检查/审核/发布/回退、诊断标注、量规候选、帮助向导。
- 管理员：演示账号资料、授权资料、任务额度配置、向导设置、前端活动备份/恢复、数据保留预览与导出。
- 全局：按身份显示导航和搜索结果，搜索课程/作业/任务/功能入口；支持 Ctrl / Cmd + K。

## 数据与演示边界

修改自动保存在当前浏览器的 localStorage 中，刷新可恢复；“工作空间设置”可导出数据和恢复初始体验。管理页备份仅覆盖学习、作业与教学投入记录，恢复前会自动再保存一份备份。`?qa=1` 使用独立验收存储，不影响正常体验数据。

目前不调用任何业务 API，不写项目数据库，不调用模型，不产生模型费用。生成、问答、模拟、策略比较与语义反馈使用本地示例；客观题只做本地选项比对，主观题留待教师复核。代码测试用例只展示，不执行程序。账号/授权/预算是前端交互资料，未实现真实安全控制。

TXT / Markdown / HTML 可读取本地文本（单文件不超过 1 MB）；HTML 仅提取文本。PDF / DOCX 用明确标记的示例片段预览，未实现解析和精确页码定位。初始学生、活动和部分学情均为示例，实际本地记录会单独标注。

实现放在 `app.js` / `styles.css` 及其功能扩展 `features.js` / `features.css` 中，不修改原有 `platform/public` 或后端。

当前功能和实测记录见 [功能验收](功能验收.md)。后续接口工作参考 [接口对齐清单](接口对齐清单.md)，其中原始缺口表保留为早期审计记录。
