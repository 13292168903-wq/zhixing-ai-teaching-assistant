# v0.4 教学试点与 LongCat 验证

## 从界面开始

运行 `platform/start.ps1`，打开 http://127.0.0.1:3810 ，登录本地教师或管理员演示角色，进入“资料与试点”。点击“初始化两门试点课与官方资料”，接入 Python、AI 通识各 20 条练习以及各 3 份官方资料快照。

课程和资料维持草稿，普通学生不可访问。教师可在“教学预览”中使用合成学员完成问答、练习、提示、提交和学习记录查询，记录保存于独立的 `var/preview.sqlite`，不混入正式统计。现有课程和三种接入方式保留。

## 资料导入与复核

上传 PDF、DOCX、Markdown、TXT、HTML（最大 5 MiB），填写出处 URL 和许可或使用依据。API 使用 JSON 中的 `content_base64` 传输二进制。解析保留 PDF 页码、DOCX 段落/表格、Markdown 标题/段落及 HTML 章节。

扫描件、加密文件、损坏或空文本会明确报错；目前不提供 OCR、公式识别或图表理解。HTML 不运行脚本或抓取链接；DOCX 不执行宏。

每份资料可查看原始片段、下载原文件，修订知识点摘要、学习目标及关联片段，并填写复核说明。候选知识点是与已有课包的对齐结果，不宣称已实现自由学科知识抽取。修订保存在草稿表，不自动覆盖已发布教学事实。

检索采用课程内 BM25、中英术语映射及前四片段。预览可检索待审核资料，普通学生只能检索人工通过的资料。相关片段命中不等于原文蕴含结论，须人工核对。

## LongCat 真实测试

底座继续采用 DS-H；新增适配器直接转换 Responses 请求与工具往返，不依赖 DeepSeek 专用协议。

- 固定模型：`LongCat-2.0`。
- 官方接口：`https://api.longcat.chat/openai/v1/responses`。
- 密钥只读取 `LONGCAT_API_KEY`，不写入源码、页面、配置文件或交付包。
- 每个教学操作最多 3 次模型请求，全局最多 30 次、费用预算 5 元；单次输出最多 800 tokens，请求体最多 24 KiB。
- 使用官方原价的输入 5 元/百万、输出 20 元/百万进行保守预留；实际费用以账户账单为准。缺失用量时保留整笔预留，失败也计数，不自动重试。
- 账本位于 `var/longcat-budget.sqlite`，重启保留。不要删除账本来绕过预算；本轮额度不足时应结束本轮并报告未完成场景。

在本机终端安全输入密钥并运行固定 10 场景：

```powershell
.\platform\test-longcat.ps1 -PromptForKey
```

该命令不会回显密钥，只在测试进程环境中使用；也支持事先配置好的进程或用户环境变量。无需把密钥发送到聊天。真实测试在独立预览环境运行，结束后不会自动把默认网页服务改成付费模式。

10 个场景为两门课程各自的有据问答、证据不足、错误理由、提示依赖和补练。结果输出到 `output/pilot-v0.4/reports/longcat-validation.json`。状态可能是缺少密钥、失败停止、存在契约失败，或真实请求完成但待人工审核。不要仅凭协议模拟测试判断真实 API 成功。

若要在网页显式开启真实模式，须在启动服务的同一进程配置 `TUTOR_ENABLE_REAL_MODEL=1`、`TUTOR_PROVIDER=longcat`、`TUTOR_MODEL_ID=LongCat-2.0` 与 `LONGCAT_API_KEY`；仍共享原预算。默认服务保持离线。

## 独立评测和受控改进

```powershell
node platform/scripts/build-pilot.mjs
node platform/scripts/record-checks.mjs
```

构建生成 80 条候选，每课 40 条、20 个 authored family；每课开发 20、验证 10、测试 10。同家族不跨分区。配对提示/状态对照及同分区重复控制均有处理记录，不把它们计为独立泛化证据。开放量规及语义独立性仍待人工复查。

`datasets/inputs.jsonl` 不含参考答案；开发/验证参考分别保存，封存参考位于 `datasets/evaluator_private/holdout/`。教学工具不能访问这些文件。分区和内容摘要可以重复构建；近重复检查不等于教师审核。

八段自建固定 Python 示例使用本地 Python 核验，Windows 换行归一化后比较。这些程序来自受信固定集合，不执行学生、外部题或模型提交代码。

候选改进只使用开发失败提出最小阈值修改，再独立比较验证集。验证须严格提高、开发不下降且无新增关键回归。未通过则拒绝；通过也只进入待人工审核。学生策略不会因自动运行而变化。

课程封存测试需确认冻结，只输出汇总。冻结标记同时保存数据库和数据目录，换进程也不能继续本轮优化。自动测试用独立合成哨兵验证该门禁，不读取实际封存参考作为开发反馈。

## 接口与数据

| 接口 | 用途 |
| --- | --- |
| `POST /api/teacher/pilot/setup` | 初始化试点课程和官方快照 |
| `GET/POST /api/teacher/materials` | 列出或上传资料 |
| `GET /api/teacher/materials/:id` | 查看片段、定位和知识点候选 |
| `POST /api/teacher/materials/:id/review` | 保存人工修订及复核状态 |
| `/api/teacher/preview/ask,practice,hint,submit,state,history` | 独立预览教学闭环 |
| `POST /api/teacher/course-evaluations` | 开发、验证、封存检查或 `action=improve` |
| `GET /api/teacher/review-package` | 导出课程、练习、预览回答及候选审核包，不含封存参考 |

首次从旧版本启动，会在迁移前通过 SQLite 在线备份保存 `var/backups/pre-v04-*.sqlite`。新表增量创建；默认运行数据、会话、原始上传和预算账本不进入源码包。

学校统一身份、真实选课授权、正式教师审定、学生代码隔离执行以及学习收益实验仍未完成。本轮材料用于工程试点和待审核教学内容，不证明真实学习收益。
