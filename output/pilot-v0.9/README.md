# 知行 v0.9 · 小知、小行角色向导

当前入口：http://127.0.0.1:3811/ 。沿用 v0.8 独立账号与试点库，不通过角色快捷登录切换身份。

## 使用

- 右下角默认显示小知。点击角色或固定“帮助”按钮打开面板。
- 在面板选择小知或小行，帮助对话保持不变。小知偏解释，小行偏步骤；权限取决于登录账号。
- 拖动角色可移动；右键或面板菜单可切换角色、本次隐藏、关闭主动提示、减少动画、清除本人帮助记录。隐藏后点固定“帮助”恢复。
- 键盘 Tab 定位按钮，Enter/空格打开，Shift＋F10 打开角色菜单，方向键移动角色，Esc 关闭面板；问答 Enter 发送、Shift＋Enter 换行。支持系统减少动画偏好。
- “问一问”包含本地快捷问题；展开回答中的“说明来源与版本”区分本地零调用和真实模型回答。复杂问题在配置真实模型时进入串行队列，失败保留输入，停止后须本人再次发送。
- “操作引导”提供登录邀请、学生入班、作业复核、教师备课、教师建班作业、管理员教师授权六条路径。可前后查看、退出或继续。向导仅导航、高亮，不提交表单；有未保存输入时暂停跳转。
- “使用说明”按当前身份显示。管理员在帮助面板底部“管理员：向导开关”独立启停；停用后仍可阅读说明。

学生不能通过向导上传课程、建课、审核或发布；这些仍由授权教师处理。未登录仅本地帮助，不开放匿名模型调用。不会自动学习聊天为平台事实，也不把帮助聊天作为掌握证据。

## 启动与依赖

需要 Node.js 24+、Python 文本解析依赖，以及经过哈希核对的 DS-H 运行包；Docker 是程序题沙箱的可选依赖。本轮沿用已验证的 DS-H 构建，未编造提交号。

在源码根目录运行：

```powershell
python -m pip install -r platform/requirements-v08.txt
.\platform\start-v09.ps1 -CheckOnly
.\platform\start-v09.ps1
# 使用真实模型，已设置 LONGCAT_API_KEY 时直接读取，否则隐藏询问
.\platform\start-v09.ps1 -RealModel
```

源码包不含私有数据库、账号密码、API 密钥和 DS-H 第三方依赖。新路径首次启动时由本人初始化管理员。若缺少运行依赖，将 `output/pilot-v0.8/知行_v0.8_DSH运行依赖.zip` 解压到源码根目录；保留其 `platform/runtime/dsh/` 目录结构。使用旧版快照是依赖复用，不是回退业务代码。依赖清单与许可见该运行包、`output/pilot-v0.8/dsh-runtime.lock.json` 及 v0.8 运行说明。

现有数据目录仍为 `platform/var/pilot-v0.8/`。新增向导表前自动备份到该目录 `backups/pre-v09-*.sqlite`。升级不改变课程审核与发布状态；恢复数据库须停服，先保留当前副本。不要把验收夹具数据库当作正式数据导入。

## 数据与隐私

按账号保存角色、屏幕内归一化位置、主动提示、减少动画偏好及引导进度。帮助记录默认纳入既有90天活动清理流程，本人可清除并随个人数据导出。清除帮助仅清除本人帮助对话和进度，不改变课程学习记录；必要的审计、模型任务及运行日志继续受原有保留规则管理，备份由管理员单独管理。

模型仅接收问题、真实身份、页面标识、有权访问课程的名称/版本/草稿状态、相关使用说明、最近三轮帮助对话和认可的导航标识。不读取密码、未提交表单、私人答案或他人记录；导航标识由服务器校验。不要主动在帮助问题中粘贴敏感信息。
