# 知行 v0.8：本机师生试点

当前入口为 v0.8，历史 v0.4—v0.7 文档只用于追溯；历史调用额度、账户与能力说明不代表当前设置。当前累计模型次数和费用默认不限，管理员可以另行设定额度。

交付包括源码与数据 ZIP、单独的 DS-H 依赖 ZIP、运行锁定清单、Python 草稿课、80 条待双教师标注的解释诊断候选、审核工作台及技术报告。正式课程没有代替教师批准。

## 从源码包启动

1. 解压“知行AI助教_v0.8_源码与数据.zip”到空目录。不要覆盖旧版数据库。
2. 将“知行_v0.8_DSH运行依赖.zip”解压到**同一目录**；应得到 `platform/runtime/dsh/apps/cli/lib/bin.js`。
3. 使用 Windows x64、Node.js 24，Python 3.11 或更高版本。依赖镜像含 Windows 原生模块；其他操作系统未验收。先运行 `python -m pip install -r platform/requirements-v08.txt`。Python 可执行文件可通过 `TUTOR_PYTHON` 指定。
4. 在源码根目录执行 `powershell -ExecutionPolicy Bypass -File platform/start-v08.ps1 -CheckOnly`。启动器仅对当前 PowerShell 进程设置执行选项，不修改全机策略。运行依赖通过内容哈希校验，不依赖开发者 D 盘仓库。
5. 离线启动：`powershell -ExecutionPolicy Bypass -File platform/start-v08.ps1`。真实模型：在末尾加 `-RealModel`，在终端隐藏输入密钥，或预先配置本机 `LONGCAT_API_KEY`。密钥不会写入前端或课包。
6. 打开 http://127.0.0.1:3811/，本人设置首个管理员账号和密码。没有默认公开账号密码。服务只监听本机。

Docker 是程序题执行的可选能力，资料审核、客观题与问答可独立使用。无可用沙箱时自由程序题明确失败，不在宿主执行代码。镜像准备沿用 `platform/sandbox` 和 `platform/scripts/prepare-sandbox.mjs` 中的脚本和摘要清单；自检只读，不自动安装或下载镜像。

## 管理员、教师、学生怎么使用

管理员：初始化 → 账号与运行治理 → 创建教师账号并授权课程。也可生成教师邀请，让教师本人设密码。仅在本机使用真实试点账号，不把演示快捷身份用于正式试点。

教师：课程工作台 → 选择 Python 首课 → 课程内容与审核。核对每份资料、32 道练习与量规，补全旧题家族和结构，查看独立教学预览，再确认当前版本。首课发布门槛包含资料与当前题目量规版本审核，程序题还需要有效沙箱记录。审核未完时保留草稿。

建课支持普通表单、批量 CSV/JSON 和受信能力插件；完整课包也可导入。批量清单中的班级名称是元数据，不代替真实班级成员授权。发布后要修改内容，先“创建待审修订版”；原课程、作业快照与作答保留。

教师：班级与作业 → 创建教学班 → 生成学生邀请 → 从已审题选1—5道题 → 创建草稿并确认发布。截止后只能查看复习；延期必须填写依据。作答复核与讲评展示规则信号、学生申请和教师修正，能导出讲评和投入时间。

学生：使用邀请建立自己的账号并确认参与说明 → 加入班级 → 打开课程作业 → 作答、解释、提示 → 查看反馈并申请复核。正确输出和解释依据分开判断；使用提示后答对不会记为独立完成。新结构复查保持同概念，没有题时说明不足。独立完成后的次日、约七日复测仅在登录时展示，不发送外部消息。

问答支持 Enter 发送、Shift＋Enter 换行、课程内历史会话、草稿保存、停止和显式重试。恢复会话只给模型最近三轮上下文；对话不作为掌握证据。

## 数据与运行

试点目录 `platform/var/pilot-v0.8/`，与 v0.7 数据分开。迁移只读旧数据库，课程内容和既有生成候选导入为待审；项目组初审不转换成教师批准。旧 12 段真实模拟保留原结果，通过新增标注记录行为是否出现。

问答、解释辅助与插件模型任务串行调度，记录任务和消耗。中断任务不会在重启后自动重放；已计费或结果未知步骤须先核查。费用是保守估算，账户账单以供应商为准。

管理员可创建 SQLite 备份。恢复前停止服务，执行页面显示的 `node platform/scripts/pilot08-restore.mjs --backup <id> --stopped`；恢复脚本拒绝覆盖仍运行的本机服务，备份当前数据库，清除会话，不回退模型消耗账本。服务使用其他端口时恢复前设置相同 `PORT`。

数据保留默认90天。管理员先预览再确认清理，清理前自动备份。清理覆盖过期活动作答、会话、关联复核/建议和任务痕迹；受影响学情清空以待新证据重建。课程内容、管理资产、消耗总账和历史备份单独保留，需管理员按试点约定管理，不能把此入口称作所有副本彻底抹除。

## 验证与真实教学门槛

`node platform/scripts/check-v08.mjs` 分组运行业务、协议和 DS-H 离线检查；真实模型与 Docker 单独报告。`build-v08.mjs` 固定种子重建诊断集，开发40／验证20／封存20，不开启原有封存评测。

技术报告不等于教学有效性结论。真实教师审核、两位教师独立标注与分歧处理、另一台设备验收、8—12人可用性观察、20—30人学习试点均需实际参与者完成。操作材料见“真实试点操作与记录.md”。
