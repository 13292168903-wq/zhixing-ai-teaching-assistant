## 使用

解压源码包，在项目根目录运行 platform/start.ps1，打开 http://127.0.0.1:3810 ，选择教师并进入“资料与试点”，初始化课程即可使用。需要 Node.js 24、本地 Python（pypdf、python-docx）及兼容 DS-H 构建；打包不包含这些上游运行时。

网页默认离线；真实验收使用独立进程和合成身份，密钥未写入交付物。如需在本机继续测试，可运行 platform/test-longcat.ps1 -PromptForKey，原预算账本仍计数，不能通过删除账本重置本轮预算。

## 文件

- course-packs：两个试点课包。
- datasets：80条输入、分区参考、审核CSV与质量报告；封存参考位于独立子目录，不提供给教学工具。
- review-package.json / human-review.csv：课程、资料和真实回答待审核包，不包含封存参考。
- reports：自动测试、真实调用历史、受控改进及封存汇总。
- screenshots：浏览器验收证据。

## 使用边界

10个真实场景的流程检查通过，不等同于教师认定回答全部正确。课程内容、开放回答和语义独立性仍待人工复核；未开展真实学生试用或学习效果实验。PDF只提取文本，扫描件需OCR；公式与图表仍需人工检查。真实模型调用保留当时的原文片段和解析版本，后续章节清洗有独立离线回归记录。
