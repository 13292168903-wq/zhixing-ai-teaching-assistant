## Assignment and reference：赋值与引用

赋值 b = a 让两个名字绑定到同一对象，不会自动复制列表。修改共享列表的一个元素后，可从两个名字观察到该变化。将 b 重新赋值为另一个对象，则只改变 b 的绑定。

## Shallow copy and nested lists：浅拷贝与嵌套列表

浅拷贝 shallow copy 建立新的外层容器，并把原容器中的对象引用放进新容器。它不会递归复制每一个内部对象。因此对于 nested list（嵌套列表），外层是不同列表，内部列表仍可共享。替换外层某个位置与修改共享内层列表是不同操作。

```python
a = [[1], [2]]
b = a.copy()
b[0].append(9)
print(a)  # [[1, 9], [2]]
b[1] = [8]
print(a)  # [[1, 9], [2]]
```

第一步修改了共享的内层列表，因此 a 也能看到 9。第二步只替换 b 的外层位置，不改变 a[1] 的引用。copy.deepcopy 会递归复制可复制的内部对象，但自定义复制行为、递归对象和有意共享对象仍需按具体类型检查。
